# Running the examples

With `chimenodes` installed, in the chimerax command line:

```
close; open <path_to_example_cxc>
```

## Nanobody and chemokine binding
```sh
close; open examples/4xt1.cxc
```

## Barnase–barstar binding animation

```sh
close; open examples/1brs.cxc
```
Uncomment the three `movie` commands in the script to save an MP4 at 30 fps.
