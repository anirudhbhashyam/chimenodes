# Showcase assets

Everything in `docs/assets/*.png` (the `*_stock` / `*_mn` pairs, `hero.png`, `gallery_*.png`) is
generated by one command:

    tools/showcase/render.sh

It needs ChimeraX (GUI build, tested with 1.11.1) and network access to RCSB on the first run
(entries 3ERT, 1STP, 1IEP, 1BRS, 6M0J). The script opens the ChimeraX window once, renders every scene
and writes `docs/assets/report.json` (git-ignored) with the ChimeraX and chimenodes versions and a
per-scene status; the exit code is non-zero if any scene failed.

Options: `--chimerax PATH` (or `CHIMERAX_EXE`), `--out DIR`, `--scenes er,sav,abl,barn,rbd,gallery`.

Scenes (all settings live in `render_showcase.py`, nothing is hand-edited afterwards):

| scene | entry | what it shows |
|---|---|---|
| `er` | 3ERT | tamoxifen-like ligand `OHT` glowing in the ER pocket (also writes `hero.png`) |
| `sav` | 1STP | biotin `BTN` in streptavidin |
| `abl` | 1IEP | imatinib `STI` in Abl kinase |
| `barn` | 1BRS | barstar (chain D) glowing on barnase (chain A) |
| `rbd` | 6M0J | SARS-CoV-2 RBD (chain E) glowing on ACE2 (chain A) |
| `gallery` | 3ERT | the same pocket under eight looks/presets |

Rendering notes learned the hard way:
- Save PNG, not JPEG. JPEG (4:2:0, and to a lesser degree 4:4:4) leaves visible blocks on the smooth
  tinted gradients; `og.png` is a small 1200x600 copy of the hero for link previews.
- Every `chimenodes` command re-applies the MN material, so the specular override (0) must be the last
  command before each screenshot.
- Keep the clip slab around the ligand small enough that no isolated surface fragment is left floating
  in the background (1STP uses +-7 A; 8 left a stray hexagon).
- Output is deterministic for a given ChimeraX build (the AO noise is a fixed hash), but GPUs/drivers
  can differ by a few levels, so diffs of re-rendered JPEGs are expected to be noisy.
